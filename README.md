# 🚌 Расписание автобусов г. Чусовой (Пермский край)

Автономный сервис расписания движения городского и пригородного транспорта Чусовского городского округа.

Сайт работает как статический веб-сервис (**Single Page Application**), собирается скриптом на Python из официальной [Google Таблицы](https://docs.google.com/spreadsheets/d/1nzePEfu6Vxki9aJG8i3t4kulrf1NXOnTrL1xPdPnIhk/htmlview) и автоматически публикуется на **GitHub Pages** по расписанию (каждые 4 часа) через **GitHub Actions**.

---

## ✨ Возможности и особенности

- 🎨 **Эстетичная палитра**: дневной скандинавский минимализм (мягкий графит и слоновая кость) и глубокий ночной режим (тёплый тёмный асфальт).
- 💡 **Интерактивный автобус с фарами**: при переходе в ночной режим у автобуса в шапке плавно **зажигаются теплые янтарные фары с объемным конусом света**. При клике на автобус — звук сигнала и всплывающее «Би-бип!».
- ⏰ **Умный расчет рейсов**:
  - Автоматическое определение времени до ближайшего рейса («*Рейс в 14:30 (через 15 мин)*»).
  - Учёт дня недели (будни / выходные / спецрейсы).
  - Сохранение всех важных примечаний водителей (*до ЦРБ*, *из АТП*, *по субботам*, *до школы*).
- 🔍 **Живой поиск**: мгновенный фильтр по номеру маршрута, названиям остановок и улицам следования.
- ⭐ **Избранное**: сохранение часто используемых маршрутов в закладки браузера (`localStorage`).
- 📱 **Mobile-First адаптив**: удобно читать расписание с любого смартфона даже при плохом интернете.

## 🚀 Как выложить на GitHub и включить бесплатный сайт (GitHub Pages)

### 1. Создайте репозиторий на GitHub
1. Перейдите на [github.com/new](https://github.com/new).
2. Назовите репозиторий (например, `bus-schedule` или `chusovoy-bus`).
3. Сделайте его **Public** и нажмите **Create repository**.

### 2. Загрузите файлы из этой папки
В терминале в папке проекта выполните:
```bash
git init
git add .
git commit -m "feat: initial bus schedule with Python parser and modern UI"
git branch -M main
git remote add origin https://github.com/<ВАШ_НИК>/<ИМЯ_РЕПОЗИТОРИЯ>.git
git push -u origin main
```

### 3. Включите GitHub Pages в 2 клика:
1. В вашем репозитории на GitHub откройте вкладку **Settings** -> **Pages** (в левой колонке).
2. В секции **Build and deployment**:
   - В выпадающем списке **Source** выберите: **`GitHub Actions`** (НЕ Deploy from a branch!).
3. Перейдите во вкладку **Actions** сверху и нажмите кнопку **Run workflow** (или дождитесь первого автоматического запуска).
4. Через 1 минуту GitHub выдаст вам публичный адрес сайта:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

Теперь сайт будет **самостоятельно обновляться каждые 4 часа** прямо на серверах GitHub без участия вашего компьютера!

## 💻 Локальный запуск и разработка

Для локального запуска нужен только стандартный Python 3.8+ (никаких дополнительных библиотек ставить не требуется):

```bash
# 1. Скачать данные из Google Таблиц и сгенерировать dist/index.html:
python updater.py

# 2. Запустить локальный сервер предпросмотра:
python updater.py --serve
# Откроется сайт по адресу: http://localhost:8000
```
